Movie Management App

A web application that lets you manage your movie collection, powered by FastAPI on the backend and React on the
frontend.

🔧 Deployment
This application is deployed on Render:
https://react-python-movies-tdge.onrender.com

🔧 Local Setup
1. Clone the repository:
   git clone git@github.com:awwilczynska/react-python-movies.git
2. Backend Setup (FastAPI):
   cd api
   pip install -r requirements.txt
   uvicorn main:app --reload
3. Frontend Setup (React):
   cd ui
   npm install
   npm start
